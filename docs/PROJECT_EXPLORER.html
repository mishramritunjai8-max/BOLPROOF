Kirana Retail Reality

Why Generic Voice AI Fails in Indian Grocery Shops

In India's 12+ million kirana shops, speed is essential, but wrong items cause massive friction.

❌ Typical Voice Assistants & Auto-Billers
  • Silent Guesswork: Silently assumes 2 kg when customer said "half sugar".
  • Cross-Item Pollution: Leaks quantities between products (e.g. 2 kg sugar makes salt 2 kg).
  • Liquid Confusion: Prompts for "2 kg mustard oil" instead of standard liter bottles.
  • Zero Review Step: Directly creates an invoice without letting the shopkeeper review what was heard.
  • Result: Wrong deliveries, awkward returns, and loss of neighborhood customer trust.
✅ BOLPROOF Deterministic Verification
  • Zero Silent Assumptions: Flags bare numbers as ambiguous; never defaults to 2 kg.
  • Clause Boundary Isolation: Splits multi-item phrases so items never contaminate each other.
  • Physical State Taxonomy: Strict distinction between solids (`g`/`kg`) and liquids (`ml`/`L`).
  • Transparent Review: Shopkeeper inspects and edits recognized Hindi text first.
  • Explicit Confirmation: Requires explicit final confirmation only when every item is clear.
Security & Defensive Engineering

Hardened Architecture & Privacy Guarantees

BOLPROOF uses an in-memory, privacy-preserving pipeline with robust defense-in-depth protections.

🔒 Zero Secrets in Frontend

`GNANI_API_KEY` is loaded solely on the Node.js backend. Client bundles contain zero private credentials.

⏱️ Sliding-Window Rate Limiting

Voice endpoints (`/api/voice/*`) enforce 30 requests/min per IP to prevent API credit exhaustion.

🛡️ Audio Magic-Byte Validation

Inspects buffer headers for genuine audio signatures (WAV, OGG, MP3, FLAC, WebM). Arbitrary binaries are rejected.

📦 Strict Upload Restrictions

Single-file `upload.single('audio_file')` with a hard 10MB limit prevents memory exhaustion attacks.

🗑️ Ephemeral Audio Processing

Audio is held strictly in memory while streaming to Gnani AI. Nothing is saved to disk or databases.

🛡️ Defensive HTTP Headers

Enforces `X-Content-Type-Options: nosniff`, `X-Frame-Options: SAMEORIGIN`, and strict origin policies.
